# Synthetic examples

Every ASC file in `synthetic-asc` is generated by `FluoLab.Core.PhDemo.WriteAscFiles`. Filenames and headers explicitly identify synthetic data. They are not laboratory measurements and must not be presented as research findings.

Import the folder into FluoLab to inspect the normal batch workflow. The fixtures deliberately include a malformed file, one spectrum missing the example wavelength, and an example manual-exclusion source. For the complete guided pH example, launch the built application with `--ph-demo` and use 600 nm. Review grouping and exclusion decisions explicitly.

The source repository intentionally contains no real spectra, PDFs, animal records, local work projects, or cached translations.
