# pH 响应分析 1.1：功能与验收说明

这是现有 FluoLab 的增量升级，继续使用 .NET Framework 4.8、WPF 和原构建方式，没有新增运行时依赖或网络功能。

## 操作与计算

导入 ASC 后点击“pH 响应分析”，依次完成样品分组、波长选择和分析结果。系列必须人工填写，文件名只建议明确的 pH 与末尾编号；确认分组前需核对同系列条件一致及单层重复设计。可单独设置参与状态，排除必须有原因。

只用原始数组中的精确波长提取强度。部分缺失须展示完整名单并确认；全缺失、无参与文件、非有限输入或分组错误时阻止分析。负强度不自动排除。数值 pH 相等时合并，同系列邻近但不同的 pH 不合并，不同系列独立统计。

结果报告测量次数 n、算术平均值、样本 SD（分母 n−1）。n=1 的 SD 不可计算并保持空白。图中展示原始点、均值、均值±SD、系列图例、波长和各组 n，没有拟合或显著性检验。不能据此推断因果或独立性。

独立导出三工作表 XLSX、2400 像素宽 PNG 和真实矢量 SVG。参数改变使旧结果失效，换批次关闭旧分析窗口。输出采用临时文件和安全替换；被占用时已有文件保留。原始汇总仍包含全部有效文件，不随预览勾选变化。

## 验收结果

- 构建通过，编译警告视为错误；Windows 自带 PowerShell 也能构建。
- 科研单元测试通过：1、2、3 得到 n=3、均值=2、SD=1；n=1 的 SD 缺失；n=2、负值、精确匹配与相近点拒绝、排除、全缺失、空数据、非有限输入、手动编辑、数值 pH、系列隔离、混合/嵌套设计、失效结果拒绝、锁定文件保全和文本转义均有覆盖。
- WPF 控件级测试通过：分组/参与状态/波长/单位改变会禁用旧导出；缺失名单对话框的明确接受与取消分别验证；新批次关闭旧分析窗口。
- 合成演示的 21 份有效光谱中，19 份纳入、1 份缺波长、1 份人工排除；1 份源文件解析失败；共 8 组。三个工作表已独立读取、重算和渲染，缺失单元格保持空白。
- PNG 已打开检查；SVG 已通过独立矢量解析和栅格化检查，包含真实文本、线段、圆和多边形，没有嵌入位图，中文正常。
- 1280×720 和 1920×1080 下的 100%、125%、150% 离屏布局模拟，共 18 张三步流程图；另检查 8 种边界状态。小窗口通过滚动查看长表、图例和结果。
- 真实 78 文件、每份 3101 点回归通过。原始工作簿保持 3102×79，并对 241878 个荧光强度逐点比对，全部与 ASC 精确一致。
- 100×3101 点示例：解析约 0.257 秒，分析约 0.000632 秒，分析 XLSX 约 0.006220 秒，机器处理合计约 0.264 秒。以上不含人工确认、界面操作及图像导出，不冒充完整用户任务耗时。
- 1.0→1.1 安装升级、安装内容哈希、已安装程序启动、重复安装和卸载清理通过。测试安装已移除。
- Microsoft Excel 原生只读打开新分析表和原始汇总表通过，数值与缺失状态正确，退出后没有新增 Excel 进程。Excel 仅用于验收，应用导出不调用 Office。
