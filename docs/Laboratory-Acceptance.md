# FluoLab 1.3 Laboratory Tools Acceptance

## Delivered scope

Three WPF caption actions; separate laboratory-tools entry; text-PDF page reading and local English-Chinese machine translation using a digest-verified optional CPU pack; page/all selection, cancellation checkpoints and escaped bilingual HTML/TXT; sanitized mouse UI, independent empty browser storage, validated explicit JSON migration and backups. Original fluorescence/pH contracts are unchanged. No Office automation, account, remote inference or online fallback is added.

## Verification evidence

- Native .NET build with warnings as errors; existing scientific, boundary, raw-export and actual WPF tests pass. Caption minimize/maximize/restore and close lifecycle were exercised. Main exit cannot bypass an active owned literature task.
- Real 78-file reference and 100 x 3,101 synthetic batch pass. Representative current run: parse 0.266469 s, pH analysis 0.000618 s, analysis-XLSX 0.016803 s; summed machine work 0.283890 s excludes human review, UI and plots. These are separate measurements, not a full user-task speed claim.
- The current raw workbook was independently reopened, compared with all 241,878 source intensities exactly, and both original sheets rendered and reviewed. The original dimensions remain 3,102 x 79 with two original sheets. The spreadsheet audit required no data or formatting changes.
- Fixed-data UI screenshot review preceded real integration. Twelve new module size/scale renders plus the original eighteen pH combinations and eight boundary states run at 1280x720/1920x1080 and 100/125/150%. A scrollable grouping viewport prevents caption-induced zero-row clipping. This simulates logical DPI, not changing physical OS scaling.
- Actual two-page synthetic PDF text extraction, PDFium pixel rendering, CPU inference and Unicode paths pass. The source digest is unchanged. Scanned/no-text, malformed PDF, source-hash mismatch and interruption after page one are verified. Incomplete page two remains explicitly untranslated. Two-page translation was approximately 1.23 s on this PC, not a general literature throughput benchmark.
- The distributed optional ZIP was SHA-256 checked, extracted through the real component installer, probed and used for actual inference. Wrong digest, unsafe/duplicate ZIP paths and cancellation are tested. Embedded third-party licenses, model attribution and artifact provenance are retained.
- Actual WPF import/translation/page navigation and bilingual export use the same document. Exported HTML was opened in a browser and both pages inspected; Chinese, source text and review warnings display. General model headings have visible mistranslations; no claim of specialist accuracy is made.
- Mouse source passes strict TypeScript checks. Validator tests cover empty/valid backup, wrong schema, duplicates, non-finite and negative counts. Actual browser checks cover empty start, one clearly synthetic new cage, persistence after reload, JSON download and the replacement confirmation appearing on import. Broader merge/split/breeding flows reuse existing logic but were not exhaustively revalidated.
- Per-user clean installation, repeated install/update, final payload hash comparison and installed module rendering pass. The temporary test installation was uninstalled and its directory/registry cleanup checked. A production 1.2-to-1.3 upgrade on another PC is not claimed.

## Material limits

No OCR, layout-preserving Chinese PDF or resumable literature project. Generic MT requires human review of terms, negation, numbers, units and reading order; number-token checks are warnings, not validation of meaning. Complex tables/equations and medical-domain quality were not benchmarked. Other CPUs/PCs may need Microsoft Visual C++ x64 runtime. The .NET fluorescence tool does not depend on the optional pack.

Mouse records are single-browser localStorage, not an encrypted database, synchronization service or compliance audit system. Fixed origin and regular external JSON backups are essential. The original project and private records are untouched; no old seed is distributed. Broader animal-operation acceptance, native WPS and physical multi-monitor/DPI testing remain pending.
