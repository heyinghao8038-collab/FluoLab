# FluoLab 1.2 功能与验收说明

## 已实现

分组搜索、待填写/有问题/待确认筛选、完成数量、错误单元格定位、按文件名对应的七列模板复制粘贴；响应图/统计/明细分离、完整图适应窗口、原始点悬停与原光谱溯源；本地工作项目保存、恢复、内容指纹与源目录重定位；未保存提醒；一键分析 ZIP 及有效源 ASC 明确选择附带。

科研口径保持不变：原始数值不修改，精确波长匹配，不插值；按系列与数值 pH 分组；测量次数 n、算术均值、样本 SD（n−1）；n=1 时 SD 缺失；人工排除和缺波长决定有记录。恢复后重新确认分组，不恢复旧结果或排除授权。无拟合、显著性检验、去异常或其他预处理。

## 验证结果

- 构建将警告视为错误，通过。原有解析、异常处理、对齐、数值、文本安全和导出测试通过。
- 新增测试覆盖 TSV 引号、换行、未知/重复文件、非有限值、格式错误、公式触发保护；未完成项目保存、参数恢复、重定位、同名内容改变、缺失文件、DTD 禁止、版本校验；ZIP 原始数据默认不含与明确附带、源字节一致、内容改变和文件占用时保留旧输出。
- WPF 控件测试覆盖筛选不改变参与状态、粘贴后失效、定位错误字段、未保存关闭取消、恢复后重新确认、原始测量点命中、溯源窗口、参数编辑失效及新批次清理。
- 真实 78 文件保持每份 3,101 点，原始工作簿 3,102 行 × 79 列。独立检查 241,878 个强度值均与源文件一致。两个原始工作表不变。
- 100 文件 × 3,101 点代表批次解析约 0.252 秒；分析约 0.0006 秒；分析 XLSX 约 0.0055 秒。三项机器处理约 0.258 秒，不含人工核对、界面和图片导出，不作为完整使用任务耗时。
- 模拟分析表全部 21 份有效样品、8 个分组、19 次纳入、1 份缺波长及 1 份人工排除经独立数值复核。三个工作表与新增指纹列已渲染查看；PNG、真实矢量 SVG 实际渲染通过。分析 ZIP 内表图与同一结果一致，默认 5 个文件、无本地绝对路径。
- 1280×720 与 1920×1080、100%/125%/150% 的 18 个步骤渲染及 8 个边界状态检查通过。这是离屏逻辑缩放模拟，并非更改操作系统设置的实机鼠标验收。
- Microsoft Excel 只读打开原始与分析工作簿、数值及缺失单元格检查通过，没有新的 Excel 进程残留。正式程序始终直接生成 XLSX，不依赖 Excel/WPS。
- 临时按用户安装、1.1→1.2 升级、四个程序组件指纹、安装后启动、重复安装及卸载清理通过。未改动实验数据。

## 限制与待实测

WPS 与其他实验室电脑、真人独立操作计时尚未验证，不能宣称完成。详见试用记录模板。极小窗口或很多系列下，适应窗口会缩小字体；可取消适应窗口滚动查看完整尺寸，导出不受屏幕缩放影响。分组表较宽，需横向滚动；源文件和校验状态已冻结在左侧。源文件内容改变时不自动迁移旧分组，需核对或重新分析。内存模拟演示不附带虚拟源文件；实际导入模拟 ASC 可验证原始文件附带。

本地 Git 仓库已初始化，未提交、推送或发布。公开源代码前仍需检查私有参考路径与验收材料，并由项目所有者确定授权方式。
