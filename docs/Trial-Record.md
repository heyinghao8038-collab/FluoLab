# FluoLab 1.4.0 真实试用记录

状态：未开展。空白记录不属于验证成果，不得填入预设满意度或效率倍数。

## 如何开展

邀请2–3位同学，各自在自己的Windows电脑完成下列任务。只用标注“模拟数据”的演示包；不收集姓名、真实实验、动物、患者记录或桌面私密截图。

1. 解压便携版或按当前用户安装；启动并检查三个窗口按钮。
2. 导入模拟ASC；查看解析失败原因和批次完整性；取消某条预览后导出原始Excel，确认有效文件没有因此消失。
3. 完成pH分组并明确确认，在600 nm分析；解释缺失值、测量次数n、n=1的SD；导出分析包，并用本机Excel/WPS打开。
4. 安装可选离线组件，导入模拟英文PDF；翻译一页，对照原页修改独立人工稿，保存核对、填写术语备注，导出HTML并核查原始机器译文仍在。
5. 小鼠模块仅创建一个模拟笼位；导出JSON并确认下载文件可打开。不要在有真实记录的浏览器中测试替换或清空。

手工基线必须完成同样范围、同样输出和核对。计时从开始操作到确认结果完成，包括人工核对；分别记录解析、机器处理及完整任务，不把解析秒数作为全流程时间。交替测试顺序并记录学习效应。
