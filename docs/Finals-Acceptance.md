# FluoLab 1.4.0 验收摘要

## 本轮功能

批次完整性：文件状态、点数、精确波长并集/交集和各文件缺点数；独立文本摘要。不评价实验质量、不改值、不自动排除、不改变原始两表导出。

离线文献核对：原文与原始机器输出只读；人工稿、明确状态、时间、20版以内的修订历史和术语备注独立保留。改稿或机器输出变化会取消相应核对确认。HTML/TXT按页追溯；术语不自动替换，不声称段落自动对齐或专业准确性认证。阅读记录退出前须导出。

工程：小鼠前端依赖清单和锁文件、独立严格类型检查/构建；Windows构建与合成测试工作流；安装、便携、模拟演示包和SHA-256。公开文件经独立副本脱敏，真实实验和动物数据不发布。
