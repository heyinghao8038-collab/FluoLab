# Public Source Verification — 2026-10-19

This record describes the isolated FluoLab 1.3.1 publication tree, not new laboratory results.

## Completed local checks

- The public source builds with the Windows platform C# compiler and warnings treated as errors. The build creates the desktop app, CLI, libraries, test runners and installer locally.
- The public synthetic test suite passes parser validation, wavelength alignment, missing-cell XLSX checks, descriptive statistics, parameter invalidation, grouping transfer, draft/source fingerprints, analysis bundles, locked output, report escaping and local-module safety.
- The 100-file x 3,101-point synthetic batch parses in about 0.250 seconds on the development machine. This is parsing only, not human end-to-end task time.
- WPF control tests pass caption/close protection and metadata/inclusion/wavelength/unit invalidation. Actual optional translation inference is skipped in this clean source tree because the separate CPU pack is intentionally absent.
- Every production `src` and installer source file matches the original local release byte-for-byte. No scientific algorithm or source-array handling changed for publication.
- The public mouse seed contains no cages, breeding entries or logs.
- The 22 example ASC files are generated by `PhDemo.WriteAscFiles`, including one deliberately invalid file. They are labeled synthetic and are not experimental observations.
- The reviewed publication files contain no source-machine username/path, known private reference endpoints or credential-pattern matches. Only the explicit synthetic ASC directory is staged.

## Excluded and not newly verified

Private laboratory fixtures, real spectra, real animal records, user PDFs, work projects, credentials, private memory, generated binaries and optional runtime/model archives are not distributed. The private reference tests remain in the original local workspace and are omitted from this public runner. This publication does not newly claim other-PC/WPS acceptance, physical alternate-DPI testing, translation quality validation or measured human productivity improvement.

Remote access must be verified separately after authentication and push. A local commit or an empty GitHub repository alone is not evidence of successful publication.
