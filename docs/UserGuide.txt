FluoLab 荧光数据分析器 1.3.1

1.3.1 窗口修复

使用 Windows 原生标题栏，右上角提供最小化、最大化/还原、关闭。拖动标题栏可移动，双击可最大化/还原，拖动边框可调整大小。首次打开自动适配当前显示器可用区域，避免高缩放下标题栏超出屏幕。
底部“快捷功能”已加大字号和按钮、增加蓝色边框；实验室工具用浅蓝色突出显示。原数据处理行为不变，已安装的离线组件继续兼容。

窗口与实验室工具

右上角提供最小化、最大化/还原、关闭三个按钮。未保存分析草稿和未导出译文仍受关闭确认保护。
主界面底部“实验室工具”提供文献阅读与离线翻译、小鼠管理两个独立入口，荧光数据和统计规则不变。
小屏或高缩放分组页面可纵向滚动，确认分组按钮位于表格下方。

文献阅读与离线翻译

首次在“安装离线组件”选择配套 FluoLab-Literature-CPU-1.0.zip（约128 MB/122 MiB，建议预留1 GB磁盘）。校验通过后安装到本机用户目录，组件可经U盘复制，后续无须联网、账号或Python安装。荧光功能不依赖它。
导入英文文本型PDF后左侧显示原页，右侧查看机器译文或提取原文；支持当前页/全文翻译、翻页和取消。原PDF不修改。已完成页可导出逐页HTML/TXT，包含原文、译文、状态、时间、模型和源指纹。退出/换文献前请导出，目前不支持恢复阅读工程或保持原排版的中文PDF。
通用模型会误译，必须核对术语、否定、数字、单位、表格和公式；数字差异提醒不等于完整准确性检查。不得据此直接作医疗或实验决策。扫描OCR不支持，多栏提取顺序可能错误。最多200 MB、1000页。
组件运行失败时核对配套ZIP及Microsoft Visual C++ x64运行库，不会改用在线翻译。可选组件保存在本地应用数据FluoLab/Components，卸载主程序时保留。

小鼠管理

点击工具页入口在本机默认浏览器打开。首次为空库，原“鼠鼠管理”项目和记录未被修改或自动迁移。笼位、分组、合笼、分笼、繁育、来源和日志沿用原模块。
记录保存在当前浏览器/配置文件的127.0.0.1:41873固定地址。换浏览器会看到不同数据，清理浏览器数据会丢失记录。请定期在“数据→导出本机数据”保存JSON到安全位置。
迁移旧记录：原系统导出JSON→新模块选择备份→校验并确认替换。先备份当前库，不自动合并。FluoLab需保持打开，关闭后浏览器不能刷新。端口占用会提示，不自动换地址。
当前是单机记录工具，没有账号、同步、加密数据库或合规审计。繁育预计日程须按实验事实核对。模拟文献演示包不含真实实验、动物或患者记录。

工作效率与进度恢复

分组页可搜索文件、筛选待填写/有问题/待确认，并查看完成数量。
“定位下一问题”或双击校验状态会跳到对应编辑字段。
展开批量设置，可复制七列模板到 Excel/WPS，连同表头粘贴回来。按源文件名对应，错误时整批不修改，粘贴后仍需确认实验含义。
“保存工作项目”将分组、排除原因、波长、单位及源文件内容指纹保存在本地 .fluolab 文件中，未填完也可保存。
下次从主窗口“打开工作项目”，确认或重新选择源文件夹。文件内容变化、新增或缺失时停止恢复；内容一致后仍需重新确认分组，不沿用旧结果和排除授权。
关闭未保存工作时可保存、放弃或取消。工作项目可能含私有条件和相对目录，请谨慎分享。
响应图、分组统计、样品明细独立查看。图表默认适应窗口；取消勾选可滚动查看完整尺寸。悬停测量点读原始值，点击或双击明细溯源至原始光谱。
“导出完整分析包”一次保存 Excel、PNG、SVG、中文说明和源文件指纹。默认不带原始 ASC；明确勾选才附带全部有效源 ASC（不含解析失败文件），并校验磁盘内容。内存演示不附带虚拟文件。

pH 响应分析

导入后点击“pH 响应分析”，按“样品分组 → 波长选择 → 分析结果”操作。
系列必须手工确认：同系列除 pH 外实验条件一致。文件名仅建议 pH 和重复编号。
Ctrl/Shift 可多选，展开批量设置可填写系列、重复类型及排除原因。
分组经明确确认后才能提取指定波长，单位为 nm，仅精确匹配原始数值。
部分缺失会展示名单并要求确认；全缺失时不能生成结果。
统计为测量次数 n、均值、样本 SD（分母 n−1）。n=1 的 SD 不可计算。
修改参数后旧结果失效。图表包含原始点、均值和 SD，不做拟合或显著性检验。
独立导出分析 Excel、2400 像素宽 PNG 和真实矢量 SVG，或导出同一结果的完整分析包。
主窗口底部“模拟 pH 演示”可用于比赛展示，推荐分析波长 600 nm。
模拟条件与结果均明确标注为模拟数据，不是真实实验结论。

快速开始

1. 启动 FluoLab。
2. 把实际存放 ASC 文件的文件夹拖到顶部区域，也可以点击“选择文件夹”。
3. 等待进度完成。异常文件会被跳过，并显示具体原因。
4. 在左侧勾选要预览的曲线。勾选只影响图表，不影响导出范围。
5. 在曲线上移动鼠标，可查看最近原始测量点的文件名、准确波长和荧光强度。
6. 点击“导出 Excel”，选择保存位置。导出始终包含全部有效 ASC。

曲线操作

- 鼠标滚轮：缩放。
- 按住鼠标左键拖动：平移。
- 双击图表或点击“恢复视图”：显示完整范围。
- “全选”：最多选择 60 条预览曲线。
- 搜索框：按文件名筛选列表。

Excel 输出

- “汇总数据”：A 列是波长，B 列起是不同文件的荧光强度。
- “处理日志”：记录源文件夹、处理数量、每份文件状态和异常原因。
- 不同波长自动按数值并集对齐，缺失测量位置留空。
- 文件是标准 xlsx，可用 Microsoft Excel 或 WPS 打开；导出时不要求安装二者。

隐私

FluoLab 不需要账号和网络，不上传实验数据，也不收集遥测。

命令行

FluoLab.Cli.exe <ASC 文件夹> [输出.xlsx]

如果不提供输出路径，结果保存在 ASC 文件夹内，并使用带时间戳的默认文件名。
