# FluoLab 分析模块接口

## Review and completeness contract (1.4)

`BatchCompleteness` reads `SpectrumBatch` and returns exact wavelength coverage without altering source arrays or analysis participation. Its report is separate from the original workbook.

`LiteraturePage.Review` and `LiteratureDocument.TermNotes` are optional derived fields. Keep `OriginalText` and `ChineseText` intact. A human draft is bound to the machine-text hash; changed output revokes reviewed state. Export includes page identity, source hash, original machine text, human revisions and terminology notes. No automatic paragraph alignment or terminology replacement is promised. Review edits are session-local until HTML/TXT export; reading-project persistence is not introduced.

## Laboratory tools contract (1.3)

Literature and mouse tools are independent workflows, not `IAnalysisModule` implementations. They do not consume or modify spectra, preview selections or pH sessions. `LiteratureDocument` contains source basename/hash, engine/model/time and ordered `LiteraturePage` source/translation/status records. `LiteratureWorker` uses bounded local child processes and atomic JSON checkpoints; `LiteratureReport` creates escaped, page-linked HTML/TXT. The optional pack is versioned, digest-verified and staged before activation. No remote inference or online fallback is registered.

Mouse assets are prebuilt from sanitized React sources with an empty version-2 store. The fixed loopback server has no write API or access to experimental files. Browser JSON imports are bounded and validated before explicit replacement. Old source/seed/store files must never be included in payloads. Keep the fixed origin stable across upgrades because browser storage is origin-bound. Third-party notices and license texts ship with the assets/component.

1.1 版包含通用整理和独立的 pH 响应分析。pH 使用显式参数契约，不能通过无参数的 `IAnalysisModule.Analyze` 猜测实验含义。其他分析仍需先明确科研规则。

## pH response contract

Version 1.2 adds `SourceIdentity`, `GroupingTransfer` and `WorkProjectStore`. File fingerprints describe the bytes read by the existing parser. In-memory spectra use a distinct tagged binary64 fingerprint. `WorkProjectStore.Restore` requires the complete valid source set and matching content, and returns an unconfirmed session with no current result. Restoring must never preserve missing-file exclusion consent. `GroupingTransfer.Parse` returns validated copied metadata; UI applies the complete returned list and revokes grouping. `AnalysisBundleExporter` consumes one current result; raw-source inclusion is explicit and fingerprint checked. Analysis workbook sample details append a source fingerprint column; original raw workbook sheets remain unchanged.

`PhAnalysisSession` owns metadata review and result validity for one `SpectrumBatch`. It exposes independent `Samples` and `Parameters`. `PhSampleMetadata` contains source path, series, pH input, repeat ID/type, analysis inclusion and exclusion reason. It never consumes spectrum preview checkboxes.

Call `ConfirmGrouping` only after explicit human review. After any metadata edit, call `RevokeGrouping`. After wavelength/unit edits, call `Invalidate`; any missing-file decision must be reconfirmed. `Preview` reports exact matches and missing filenames. Set `AllowMissing` only after showing that complete list and receiving confirmation. `Calculate` returns a snapshot. Export must call `RequireCurrentResult` so stale configurations cannot be exported.

`PhAnalysisResult.Samples` includes every valid source file with nullable intensity, explicit status and reason. `Groups` uses exact series plus numeric pH, measurement count, mean and nullable sample SD. It stores no raw array mutations and no absolute source paths in reports. Public demonstration data is deterministic and explicitly synthetic.

The type name `Independent` represents a user-confirmed single-level design, not a conclusion inferred from filenames. Mixed/nested repeats are rejected. No significance tests, fits or preprocessing are performed.

核心接口：

```csharp
public interface IAnalysisModule
{
    string Id { get; }
    string DisplayName { get; }
    bool IsAvailable { get; }
    ModuleResult Analyze(SpectrumBatch batch, CancellationToken cancellationToken);
}
```

`SpectrumBatch` 提供以下稳定信息：

- `SourceFolder`：当前实验文件夹。
- `Files`：全部 ASC 的解析结果，包括跳过文件及原因。
- `ValidDatasets`：所有有效数据集。
- `DiscoveredCount`、`SuccessCount`、`SkippedCount`：处理统计。

每个有效数据集包含 `DisplayName`、`SourcePath`、`Wavelengths`、`Intensities` 和 `PointCount`。分析模块只读取这些标准字段，不得重新解析 ASC 原文件。

模块不得上传实验数据、静默修改原始数组或在未确认科研规则时推断文件名语义。需要额外参数时，由模块自己的界面收集，并在结果日志中记录参数。
