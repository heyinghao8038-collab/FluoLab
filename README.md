# FluoLab

Local-only Windows fluorescence-spectrum organization and traceable pH descriptive analysis. The user interface and analysis reports are Chinese. Built for Windows 10/11 x64 with the inbox .NET Framework 4.8, WPF and C# compiler. No Office automation, cloud service, telemetry or production package restore.

This repository contains the privacy-reviewed **1.3.1 source snapshot** for competition review. It includes the fluorescence application, installer source, optional-module source/assets, synthetic tests, and clearly labeled synthetic ASC examples. It does not contain laboratory measurements, animal records, personal workspace memory, prebuilt executables, or the optional translation runtime/model pack.

## Main workflow

1. Import a folder of PerkinElmer ASC spectra (top-level files only).
2. Review valid and skipped files, then overlay selected spectra with original-point hover and zoom.
3. Export every valid spectrum to an aligned XLSX workbook: `汇总数据` and `处理日志`. Missing measurements stay blank.
4. Optionally confirm sample grouping and extract an exact wavelength for pH descriptive statistics and PNG/SVG/XLSX exports.

Preview selection does not change raw export scope. Analysis does not alter original spectra. No fitting, significance testing or automatic outlier removal is performed.

## Build and verify

Run in Windows PowerShell from the project root:

```powershell

.\tests\Run-NewAppTests.ps1
.\artifacts\build\FluoLab.UiTests.exe
```

Distribution: `dist/FluoLab/FluoLab.exe` (keep sibling DLLs and Modules) and the per-user `dist/FluoLab-Setup-1.3.1.exe` installer. Version 1.3.1 restores the native Windows frame, fits startup windows to the actual monitor/DPI and promotes footer actions. Detached WPF renders do not prove native-title-bar visibility; desktop verification is separate. See the Chinese operating guide for scientific rules, work projects and export bundles.

These files are created locally by the build; they are not committed to this repository. This is a Windows desktop application, not a browser-hosted demo. Private reference assertions are excluded from the public test runner. The public suite generates its own synthetic fixtures, including the 100-file x 3,101-point batch.

## Synthetic demonstration

The files in `examples/synthetic-asc` are generated by `PhDemo.WriteAscFiles` and are explicitly marked synthetic. They include an intentionally invalid file and wavelength/exclusion edge cases. They are not experimental observations.

After building, start `dist/FluoLab/FluoLab.exe --ph-demo` for the guided synthetic pH workflow, or import `examples/synthetic-asc` for the normal folder workflow. Use 600 nm for the synthetic pH example. A reviewer must still check and confirm grouping; a filename is not evidence of experimental independence.

See [the Chinese user guide](docs/UserGuide.txt), [the module contract](Modules/模块接口说明.md), [publication scope](docs/Source-Publication.md), and [public-source verification](docs/Public-Source-Verification.md).

## Scope

ASC import, aligned raw XLSX export, exact original wavelength extraction, explicit grouping, arithmetic mean and sample SD, vector response graphs, source traceability, local draft resumption and opt-in raw-source analysis bundles. No fitting, significance tests, inferred experimental independence or automatic preprocessing.

The synthetic demo is explicitly labeled and may be used without exposing laboratory measurements. Run `FluoLab.exe --ph-demo`.

## Local laboratory tools (1.3)

The laboratory-tools entry opens separate PDF and mouse workflows. WPF windows expose minimize, maximize/restore and close while retaining draft guards.

PDF translation requires a separately supplied, digest-matched `FluoLab-Literature-CPU-1.0.zip` (~122 MiB; allow 1 GiB free disk for staged installation). The pack is not included in this source repository. Select it in the literature window to verify its release hash and install per user. It includes embedded Python, PDFium and an attributed OPUS-MT English-Chinese neural translation model. No account, external model endpoint or online fallback is used. An x64 Microsoft Visual C++ runtime may be required on other PCs; the probe reports missing native dependencies. Fluorescence remains independent of this optional runtime. Scanned OCR, translated-PDF layout reconstruction and resumable reading projects are not implemented. Page-linked HTML/TXT and original-page images support review; generic machine output is not a certified scientific or medical translation.

Mouse management reuses the existing cage/group/breeding/log UI with an empty seed and separate storage key. A GET/HEAD-only server binds `127.0.0.1:41873`, checks Host and serves fixed assets under restrictive CSP. Records belong to the chosen browser/profile's localStorage, not the installer. Export JSON backups before clearing storage or moving PCs. Original records are untouched; migration requires validated JSON import with replacement confirmation. No Node runtime is shipped. This is not multi-user synchronization or regulated animal-facility compliance software.

The normal .NET build uses prebuilt mouse assets without package restore. Developer rebuild: `node scripts/Build-MouseModule.mjs <existing-node_modules>` uses the existing mouse project's React 19.2.6, Vite 8.0.13 and TypeScript, performs strict checks, and writes `artifacts/mouse-bundle/app.js`; copy it to `Modules/Mouse/app.js` before building. `scripts/Build-LiteraturePack.py` builds the optional pack and records versions, sources, hashes and licenses. Third-party notices ship with both modules.
